# Installing VS Code

VS Code is the code editor we'll use throughout the course. The installation is the same process on Windows and Mac.

> 📝 **Already have VS Code?** Nothing to do — it keeps itself up to date. Skip to the [Git installation guide](README.md).

## Steps

1. Go to [https://code.visualstudio.com/download](https://code.visualstudio.com/download)
2. Click the download button for your operating system.
   - **Windows:** click the Windows button (this is a single installer — no version choice needed).
   - **Mac:** click the Mac button. This downloads the **Universal** build, which works on all Macs — you do not need to check your chip type for this one.
3. Once downloaded, run the installer:
   - **Windows:** open the downloaded `.exe` file and follow the setup wizard. The default options are fine — just click Next through the steps.
   - **Mac:** open the downloaded `.dmg` file, then drag the VS Code icon into your **Applications** folder.
4. Open VS Code once to confirm it starts (Start Menu search on Windows, Applications folder or Spotlight search on Mac).
