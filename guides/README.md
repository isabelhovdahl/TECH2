Please install the three programs below and confirm they work using the verification checklist.

| Tool | Guide |
| --- | --- |
| VS Code | [Install guide](install-vscode.md) (same steps for Windows and Mac) |
| Git | [Windows](install-git-windows.md) &nbsp;·&nbsp; [Mac](install-git-mac.md) |
| Miniforge | [Windows](install-miniforge-windows.md) &nbsp;·&nbsp; [Mac](install-miniforge-mac.md) |

Once all three are installed, go through the **[verification checklist](verify-installation.md)** to confirm everything is working.

If something doesn't work, don't worry — we've reserved time in the first lecture to help. Come to class with a note of what went wrong (e.g. a screenshot of any error message).
